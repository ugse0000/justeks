# JUSTEKS Brand Guidelines

**Version 1.0 · Fabric, Perfected.**

These guidelines cover the JUSTEKS identity: what it is for, how it is drawn,
and the rules that keep it consistent across the site, print and social.

---

## 1. Brand core

JUSTEKS is a **fabric house and global B2B textile supplier**, not a fabric shop
and not a consumer fashion label. Everything in this identity follows from that.

| | |
| --- | --- |
| Tagline | Fabric, Perfected. |
| Positioning | BRITISH ORIGIN. GLOBAL REACH. |
| Strapline | Textile Expertise Since 2004. |
| Pillars | EST. 2004 · BRITISH ORIGIN · TEXTILE EXPERTISE · GLOBAL SUPPLY |

**Character:** dependable, technically competent, international, measured,
timeless, premium but unshowy.

### Audience

Professional buyers, not end consumers:

- Textile mills and converters
- Garment manufacturers
- Fashion brands and private-label producers
- Wholesalers and distributors
- Procurement and sourcing teams

They are judging supply reliability, technical specification and consistency.
The identity has to look like it belongs to a supplier that ships on time.

## 2. The mark

### The idea

The monogram is a **J** built from three parts: a short top serif, a straight
stem, and a true semicircular bowl.

- **The stem** reads as the warp — straight, tensioned, structural.
- **The bowl** is the turn of a finished fabric edge, a **selvedge**. It is a
  real half-circle, not a calligraphic sweep, because a selvedge is a
  controlled, machine-made edge, not a flourish.
- **The serif** is what stops the mark reading as a hook or a U at small sizes,
  and gives the letter a settled, established stance.

The mark is drawn monoline: one stroke weight, butt caps, mitre joins. No
tapering, no optical thick-and-thin. This is a supplier's mark, not a fashion
house's signature.

The wordmark is drawn from the same alphabet, so the J in JUSTEKS repeats the
monogram's serif exactly. The two are visibly the same letterform.

### The lockup and its hairline

In the horizontal lockup the monogram is set **1.5×** the wordmark's cap height
and separated by a single gold hairline.

This is not decoration. At equal size the monogram and the wordmark read as
"J JUSTEKS", because the mark is the same letter the word starts with. The size
step plus the rule separate the emblem from the name. The hairline is also the
one place gold earns its keep in the logo system — the width of a single
selvedge thread.

**The lockup is complete without it.** Single-ink versions set the rule in the
same colour as the mark.

- **Wordmark** where an emblem would compete with other marks, such as a partner
  or supplier lineup.

## 4. Clear space and minimum size

### Clear space

The measure is **the stroke weight of the monogram's stem** — call it `x`.
In the lockup, `x` is one sixth of the monogram's height.

Keep at least **1×** clear on every side. Nothing enters that band: no type, no
rules, no image edges, no other logos.

```
┌─────────────────────────────┐
│         1x clear            │
│   ┌─────────────────────┐   │
│1x │   J │ JUSTEKS       │1x │
│   └─────────────────────┘   │
│         1x clear            │
└─────────────────────────────┘
```

### Minimum sizes

Below these the wordmark's counters close up and the mark stops being legible.

| Mark | Screen | Print |
| --- | --- | --- |
| Lockup | 90 px wide | 24 mm wide |
| Wordmark | 70 px wide | 20 mm wide |
| Monogram | 16 px tall | 5 mm tall |

The monogram was drawn to survive 16 px: at that size its stroke is still 2.5 px
and the serif still registers. This is why the monogram, not the lockup, is the
favicon and the mobile header mark.

## 5. Misuse

Never:

- Add a gradient, drop shadow, glow, bevel or any 3D treatment
- Fill the mark with a photograph or texture
- Recolour it outside the palette, or set the whole mark in gold
- Stretch, condense, skew or rotate it
- Redraw, re-space or re-set the wordmark in another typeface
- Outline or add a keyline to the mark
- Place it on a busy area of a photograph without a plain panel behind it
- Put it inside a box, badge, crest, shield or roundel
- Pair it with a Union Jack, a globe, a needle, a thread spool, a sheep, a leaf,
  a fabric roll, a weave grid, an infinity symbol or a chain
- Add the tagline inside the logo file — the tagline is set as separate type in
  corporate applications, never locked to the mark
- Use the mark below its minimum size

The identity must work in one ink. If a treatment fails in flat black on white,
it is wrong.

## 6. Colour

Gold is a **hairline accent only** — rules, eyebrows, the active nav underline,
the lockup's separator. Never a fill, never a gradient, never a glow. Keep it
under roughly **1%** of any page or page-equivalent surface.

| Name | HEX | RGB | CMYK (approx.) | Role |
| --- | --- | --- | --- | --- |
| Near black | `#0A0A0A` | 10, 10, 10 | 0 / 0 / 0 / 96 | Primary ink, dark grounds |
| Ink | `#141414` | 20, 20, 20 | 0 / 0 / 0 / 92 | Body text on pale grounds |
| Warm ivory | `#FAF8F4` | 250, 248, 244 | 0 / 1 / 2 / 2 | Primary page ground |
| Ivory | `#F4EFE6` | 244, 239, 230 | 0 / 2 / 6 / 4 | Alternate section ground |
| Cream | `#EDE6D9` | 237, 230, 217 | 0 / 3 / 8 / 7 | Hairline rules, dividers |
| Muted gold | `#C8A96A` | 200, 169, 106 | 0 / 16 / 47 / 22 | Accent only |
| Muted | `#6B6257` | 107, 98, 87 | 0 / 8 / 19 / 58 | Secondary text, pale grounds |
| Muted on dark | `#A79E92` | 167, 158, 146 | 0 / 5 / 13 / 35 | Secondary text, dark grounds |

**CMYK values are conversions, not press-matched.** Have them proofed before a
production run. For large solid blacks, ask the printer for a rich black build
rather than 0/0/0/96.

### Gold never carries text on a pale ground

Muted gold on warm ivory measures **1.98:1** — far below the WCAG AA minimum of
4.5:1. On near black it measures 8.4:1 and is fine.

So: gold text only on dark grounds. On pale grounds, an eyebrow is set in
`--jt-muted` with a gold hairline beside it. This rule is pinned by a test in
the web project (`src/design/contrast.test.ts`).

## 7. Typography

| Role | Typeface | Notes |
| --- | --- | --- |
| Headings | **Newsreader** | Light to medium weights only |
| Body | **Instrument Sans** | 400 / 500 / 600 |
| Technical data | **IBM Plex Mono** | Counts, GSM, widths, article numbers |

Rules:

- **No heavy or bold serif.** Power comes from scale and space, not weight.
- Set technical values in mono. A GSM figure, a width in centimetres and a
  composition percentage are data, and should look like data.
- Generous vertical space. Let sections breathe rather than filling them.
- The wordmark is **artwork, not text**. Never set "JUSTEKS" in a system font
  and call it the logo — use the wordmark file or the `Logo` component.

---

## 8. Layout

- Page maximum **1440 px**, content column **1200 px**
- Twelve-column thinking underneath
- Generous vertical rhythm on a 4 px spacing scale
- Hairline dividers, never heavy rules or boxes
- No gradients, no glossy effects, no drop shadows anywhere in the system
- WCAG 2.2 AA as a floor
- Honour `prefers-reduced-motion`
- Keyboard focus must stay visible — never remove focus styling

---

## 9. Voice

Write for a professional buyer who is comparing suppliers.

**Do:**

- Be precise, calm and evidence-led
- Lead with concrete facts: origin, construction, GSM, width, handle, end use
- Keep sentences short and load-bearing
- Say what a fabric *is* before saying what it is *for*

**Do not:**

- Claim superlatives you cannot evidence — "the world's best", "flawless quality"
- Make unverified environmental or certification claims
- Write luxury-poetic or fashion-editorial copy
- Invent product codes or article numbers

### Turkish and English

Both languages carry the same information and the same structure. Turkish is
not a decorative translation — it is the same document.

- Identical URL slugs in both languages; only the `/tr` prefix differs
- Same section order, same headings, same block structure per page
- Turkish carries the same content in noticeably fewer but longer words. Judge
  length by characters, not word count.
- Brand terms stay in English: JUSTEKS, Fabric, Perfected., BRITISH ORIGIN.
  GLOBAL REACH.
- Technical units stay international: GSM, cm, kg, Incoterms

### Technical data format

Write specifications the same way every time:

```
Composition   100% Linen
Weight        180 GSM
Width         150 cm
Finish        Enzyme washed
Origin        United Kingdom
```

Use mono type, one value per line, units always stated. Ranges use an en dash
with the unit once: `160–180 GSM`.

## 10. Certifications and sustainability

This is the strictest rule in the system.

- A certification mark or name — **OEKO-TEX, GOTS, GRS or any other** — appears
  **only** where the specific article genuinely holds it.
- Never at category level. Never on a collection page. Never as decoration in a
  footer, a letterhead or an email signature.
- Never state or imply a general environmental claim that cannot be evidenced
  for the specific goods being described.
- Do not describe the company as sustainable, eco or green as a positioning.
  Describe what is actually true of a given article, and stop there.

If in doubt, say nothing. A supplier that overclaims once is not trusted again.

## 11. Photography

Photography should look like the trade, not like a campaign.

**Choose:**

- Real fabric, real construction — close enough to read the weave or knit
- Production and professional-use contexts
- Controlled, natural light
- Low saturation, neutral and earthy tones that sit with the palette

**Avoid:**

- Over-lit, high-gloss fashion campaign imagery
- Heavy colour grading or filters
- Stock that looks staged, or models presented as customers
- Any asset with a watermark, an unclear licence, or from a paid tier the
  project is not subscribed to

**Licensing:** every image must be traceable. Keep `docs/image-credits.md`
up to date with the file, the photographer and the source for each photograph.

## 12. Applications

Editable templates live in `brand/templates/`. Every field a real document
would fill in is left as a bracketed placeholder such as `[LEGAL NAME]`,
`[PHONE]` or `[ADDRESS]`. **Never ship a template with invented details.**

| Template | Size | Notes |
| --- | --- | --- |
| `business-card-front.svg` | 85 × 55 mm | Dark ground, lockup, positioning line |
| `business-card-back.svg` | 85 × 55 mm | Pale ground, monogram, contact fields |
| `letterhead-a4.svg` | A4 | Lockup, hairline, statutory footer |
| `quotation-cover.svg` | A4 | Dark cover, reference and validity block |
| `woven-label.svg` | 60 × 30 mm | **Single ink** — rule set in the mark's colour |
| `shipping-document-header.svg` | 210 × 45 mm | Consignee and Incoterm fields |
| `social-profile.svg` | 1000 × 1000 | Monogram, dark ground |
| `social-post.svg` | 1080 × 1080 | Lockup, headline and supporting line |
| `email-signature.html` | — | Table-based, inline styles, Outlook-safe |

### Social

- **Avatar:** monogram on near black. The lockup is unreadable at avatar size.
- **Posts:** lockup top-left, headline in Newsreader, supporting line factual.
- Positioning line at the foot, letterspaced, never inside the logo file.
- One idea per post. No collages, no stickers, no emoji in brand voice.

### Documents

- Lockup top-left, at consistent size across a document family
- One gold hairline per page at most
- Statutory details (legal name, registered address, tax and MERSIS numbers)
  belong in the footer, set small in muted
- Quotations and shipping documents set every figure in mono

## 13. Regenerating the assets

All artwork is generated from one geometry module, so the marks cannot drift
apart:

```
brand/tools/geometry.mjs        # the numbers — every shape derives from these
brand/tools/svg.mjs             # SVG emitters
brand/tools/build-brand.mjs     # writes web/public/brand/* and the React paths
brand/tools/build-templates.mjs # writes brand/templates/*
```

```bash
node brand/tools/build-brand.mjs      # marks, icons, manifest, social card
node brand/tools/build-templates.mjs  # corporate templates
```

`build-brand.mjs` also writes `web/src/components/brand/paths.ts`, which the
`Logo` React component reads — so the mark on the site and the mark in the
asset folder are the same geometry by construction.

PNG output needs `sharp`. Without it the script still writes every vector file
and reports what it skipped.
